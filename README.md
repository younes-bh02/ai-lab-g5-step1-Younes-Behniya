# پروژه آزمایشگاه هوش مصنوعی: مسیریابی شهری با BFS

## ۱. معرفی پروژه
در این پروژه نقشه‌ای ساده از شهر به شکل یک شبکه دوبعدی مدل‌سازی می‌شود. عامل هوشمند باید با دوری از موانع، مسیری معتبر از مبدأ به مقصد پیدا کند.

## ۲. تعریف مسئله
- **ورودی:** نقشهٔ شبکه‌ای، مختصات مبدأ و مختصات مقصد
- **خروجی:** مسیر معتبر از مبدأ به مقصد یا پیام «مسیر پیدا نشد»
- **فرض‌ها:** نقشه معلوم و ثابت است؛ حرکت فقط به بالا، پایین، چپ و راست مجاز است؛ هزینهٔ تمام حرکت‌ها برابر است.
- **چالش توسعهٔ انتخاب‌شده:** تبدیل محیط به شبکهٔ دوبعدی

## ۳. مؤلفه‌های PEAS
| مؤلفه | تعریف در پروژه |
|---|---|
| معیار عملکرد (P) | رسیدن به مقصد، عبور نکردن از موانع، کمینه‌کردن تعداد حرکت‌ها و ثبت زمان اجرا و گره‌های گسترش‌یافته |
| محیط (E) | شبکهٔ دوبعدی نمایانگر مسیرها و نقاط مسدود شهری |
| عملگرها (A) | حرکت به بالا، پایین، چپ و راست |
| حسگرها (S) | دریافت نقشه، مختصات فعلی، خانه‌های مجاور و موقعیت مقصد |

## ۴. ویژگی‌های محیط
- کاملاً مشاهده‌پذیر
- قطعی، با فرض ثابت بودن نقشه
- ترتیبی
- ایستا
- گسسته
- تک‌عاملی

## ۵. معیارهای ارزیابی
۱. آیا مسیری پیدا شده است یا خیر.
۲. تعداد حرکت‌های مسیر نهایی.
۳. تعداد گره‌های گسترش‌یافته.
۴. زمان اجرای الگوریتم برحسب ثانیه.
۵. اعتبار مسیر: قرار داشتن در محدودهٔ نقشه و عبور نکردن از خانه‌های مسدود.

وقتی هزینهٔ تمام حرکت‌ها یکسان باشد، الگوریتم جست‌وجوی عرضی (BFS) مسیری با کمترین تعداد حرکت پیدا می‌کند.

## ۶. فایل‌های پروژه
- `check_env.ipynb`: بررسی نسخهٔ پایتون و کتابخانه‌های لازم.
- `environment.yml`: مشخصات محیط پایتون و وابستگی‌ها.
- `notes/risks.md`: ریسک‌های پروژه و راهکارهای کاهش آن‌ها.
- `routing_bfs.ipynb`: پیاده‌سازی و آزمایش سناریوهای مسیریابی.

## ۷. روش اجرا
ابتدا محیط را ایجاد و فعال کنید:

```bash
conda env create -f environment.yml
conda activate ai-lab-g3-step1
jupyter notebook
```

ابتدا فایل `check_env.ipynb` و سپس فایل `urban_routing_bfs_evaluation.ipynb` را باز کنید و سلول‌ها را از ابتدا تا انتها اجرا کنید.

## ۸. محدودیت‌ها و توسعه‌های آینده
نقشهٔ فعلی ساده‌سازی شده است و از GPS واقعی، نقشهٔ خیابان‌های واقعی، ترافیک زنده یا هزینه‌های متفاوت مسیر استفاده نمی‌کند. در آینده می‌توان BFS را با DFS و A* مقایسه کرد و هزینه‌های متفاوت برای مسیرها یا موانع پویا در نظر گرفت.
